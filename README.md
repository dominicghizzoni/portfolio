# Portfolio Website

A modern interactive developer portfolio built with React, Vite, Tailwind CSS, and React Three Fiber.  
This site showcases my projects, technical skills, and experience through a responsive 3D gallery experience designed for both desktop and mobile users.

---

## Features

- Interactive 3D project gallery
- Responsive design for desktop and mobile
- Touch swipe support for mobile navigation
- Smooth animations and transitions
- Individual project pages with live demos and source code
- Dynamic project-themed UI styling
- Contact section for networking and collaboration
- Fast performance powered by Vite

---

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router

### 3D / Animation
- React Three Fiber
- Drei
- Three.js

### Icons & UI
- Lucide React

---

## Project Structure

```bash
src/
├── assets/        # Images, icons, models
├── components/    # Reusable UI components
├── models/        # 3D scene models
├── pages/         # Main application pages
├── utils/         # Helper functions and theme utilities
└── App.jsx
````

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/your-portfolio.git
cd your-portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

The app will start locally at:

```
http://localhost:5173
```

---

## Build for Production

```bash
npm run build
```

---

## Preview Production Build

```bash
npm run preview
```

## Customization

To personalize the portfolio:

* Modify color themes in utility files
* Edit page content inside the `pages/` directory
